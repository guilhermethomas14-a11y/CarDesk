# Backlog da Sprint - CarDesk

## Product Goal

Criar uma versão funcional do CarDesk para registrar e acompanhar chamados de suporte.

## Histórias de Usuário

### US01 - Cadastrar chamado
**Como** solicitante,  
**quero** cadastrar um chamado,  
**para** registrar minha necessidade.

**Prioridade:** Alta

---

### US02 - Consultar chamados
**Como** usuário,  
**quero** consultar os chamados cadastrados,  
**para** saber quais solicitações estão pendentes.

**Prioridade:** Alta

---

### US03 - Alterar status
**Como** responsável pelo atendimento,  
**quero** alterar o status de um chamado,  
**para** acompanhar sua situação.

**Prioridade:** Alta

---

### US04 - Excluir chamado
**Como** usuário,  
**quero** excluir um chamado,  
**para** remover solicitações que não são mais necessárias.

**Prioridade:** Média

---

### US05 - Criar testes
**Como** equipe de desenvolvimento,  
**quero** criar testes automatizados,  
**para** verificar o funcionamento do sistema.

**Prioridade:** Média

---

### US06 - Configurar CI/CD
**Como** equipe de desenvolvimento,  
**quero** configurar integração contínua,  
**para** verificar automaticamente os testes a cada alteração.

**Prioridade:** Média

## Ordem de Prioridade
